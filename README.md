# Caixa Eletrônico em TypeScript

Projeto simples de terminal desenvolvido em TypeScript para praticar lógica de programação.

## Funcionalidades

- Depositar dinheiro
- Sacar dinheiro
- Mostrar saldo
- Sair do sistema

## Conceitos utilizados

- if / else if
- while
- validação com isNaN
- variáveis
- TypeScript
- prompt-sync

## Tecnologias

- TypeScript
- Node.js

## Como executar

1. Instale as dependências:

```bash
npm install
```

2. Execute o projeto:

```bash
npx ts-node index.ts
```
